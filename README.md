# 🏡 Energy Value Index – Porto – Andressa Avelar Belo

Projeto focado em análise de preços imobiliários, estudos comparativos entre regiões, fatores socioeconômicos e modelos preditivos simples aplicados ao mercado habitacional do Porto.
Este repositório foi criado para demonstrar competências técnicas relevantes para funções como Data Analyst, Business Analytics, Research Analyst, Real Estate Analytics e Data Engineering (nível introdutório).

---

## 🎯 Objetivos do Projeto

- Analisar preços de imóveis no Porto considerando localização, tipologia, metragem e fatores socioeconômicos.
- Criar dashboards e visualizações que permitam comparar regiões, bairros e zonas da cidade.
- Explorar relações entre preço/m², distância ao centro, acessos, serviços e transportes.
- Desenvolver insights que suportem decisões de compra — pessoais e profissionais.
- Construir um case sólido baseado em análise de mercado guiada por dados.

## 🚀 Desenvolvimento do Projeto

1. Coleta de Dados

     - Extração manual ou via scraping de listings de imóveis (Idealista, Imovirtual, Casa Sapo).
     - Padronização das variáveis: preço, m², tipologia, zona, distrito, coordenadas.

2. Limpeza & Tratamento
     - Remoção de outliers.
     - Normalização de endereços e conversão de tipologia.
     - Geocodificação quando necessário.

3. EDA – Análise Exploratória
     - Preço/m² por bairro (Mapa de calor).
     - Variação entre zonas (centro, Paranhos, Campanhã, Ramalde, Foz…).
     - Distribuição de preços vs. metragem.

4. Modelagem Simples (Opcional)
- Regressão linear para prever preço baseado em m² + localização.
- Comparação entre bairros.

5- Insights & Conclusões

     - Identificação dos bairros “melhor custo-benefício”.
     - Ranking baseado em: preço, transporte, comércio, qualidade de vida.
     - Observações estratégicas para tomada de decisão futura (Documentação)
